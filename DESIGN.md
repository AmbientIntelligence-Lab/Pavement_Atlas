# Atlas 1.2 integration

This is an extension of the supplied Atlas, preserving its visual system: light #f5f5f7 page, white surfaces, #1d1d1f text, #0071e3 interaction accent, system sans serif typography and rounded controls. Existing section titles, explanatory content, illustrations, workbook and dataset records are retained.

The new sensor explorer uses those same colors and type conventions. Its desktop layout is model selector, model header, interactive stage beside inspector, then searchable sensor index. Under 900px the inspector moves below the stage; under 500px the sensor index becomes one column and the model selector becomes two columns. Hardware colors describe sensor families, independent of the Atlas action accent.

The global filters use the original controls in a three-column in-page panel, reducing to two and one columns. They remain one shared filter state. The two simulations share vehicle source geometry and selection, but keep independent camera and scene state.

No existing site-wide visual redesign or changes to dataset claims are included.
