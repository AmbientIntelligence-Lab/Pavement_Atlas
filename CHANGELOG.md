# Update history

## 1.3.0 — 12 October 2026

- Rebuilt the catalog from the requested v4.0 Word and Excel documents: 233 retained records, including 56 retained AV additions; preserved existing DS identifiers.
- Replaced the former 40-check common score with the revised six-dimension, 16-check core and separate Labeled-16/Unlabeled-13 cohorts. Matched all 699 baseline score outputs to the workbook. Preserved unresolved evidence and separate reuse gates.
- Added permanent dataset detail links, full source metadata, check rationales, JSON/BibTeX downloads, citation guidance and machine-readable Dataset metadata.
- Updated countries, facets, counts and source access fields from the current catalog. Missing source years and camera viewpoints remain unreported.
- Retained the Atlas's light visual system and section order. Added consistent keyboard interactions and credited distress photographs.
- Expanded the shared fleet with a generic driver-assisted car and a lab survey vehicle. Added per-vehicle dataset references that distinguish collection provenance from related examples.
- Added a standalone Three.js urban driving workspace with two crossroads, signal phases, surrounding traffic, demo cruise, keyboard/touch controls and four camera views.
- Added eight road-surface examples—pothole, transverse cracks, longitudinal cracking, alligator cracking, rutting, raised patch, raveling and utility cover—plus a smooth reference. Added daylight/dusk/night, dry/rain/fog conditions, headlights and street lighting.
- Added a live generated body-response graph and CSV trace export. Surface displacement, weather, traffic and vehicle dynamics remain illustrative; exported traces are not measured road data or IRI.
- Moved community submissions to a dedicated page with required name/email, a metadata schema and real XLSX generation. Included a Google Apps Script receiver with server validation, fixed recipient, rate limits, duplicate protection and receipt pages. Automatic email remains disabled until owner deployment and live testing; the download/manual-email fallback works immediately.
- Added a user guide, usage screenshots, source provenance, reproducible import/build checks and a GitHub Pages deployment workflow.
